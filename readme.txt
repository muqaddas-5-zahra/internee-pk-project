# Resume Screening Automation - Internee.pk Internship Task
Objective: Automate resume filtering to match candidates with job openings.
**Tools Used:**
- Python
- spaCy for NLP
- TF-IDF & Cosine Similarity for matching
**Features:**
- Extracts skills and experience from resume
- Calculates match score with job description
